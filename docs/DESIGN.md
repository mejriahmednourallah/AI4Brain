# AI4BRAIN visual direction

A calm learning workspace with a slate sidebar, warm near-white surfaces, blue primary actions, fine grid lines, and restrained amber uncertainty notices. Use a professional system sans stack (Segoe UI/Arial), monospaced numeric evidence labels, 16px body text, clear hierarchy, and 44px interactive targets. Main content maximum width 1200px; assessment canvas focuses on one task. Analytics is precise and readable; RPG adds a quest/skill-tree framing while retaining every evidence qualification.

Skill search reviewed: first match was enterprise sales (not suitable); refined education query returned a useful indigo learning palette and accessibility guidance, but childish clay typography is not appropriate for this general-audience POC. Selected deliberate product-specific interpretation: minimal blue/slate design, no fake metrics, no stock logos/testimonials, no external font/network dependency.

Mandatory: visible keyboard focus, meaningful button labels, responsive 375/768/1024/1440, no horizontal overflow, reduced-motion support, color-independent states, loading/retry UI, disabled state during submission, interruption handling, unassessed rather than zero. Use Lucide/SVG icons, not emoji. All geometric tasks render original SVG/config, not raster or copyrighted tests.
