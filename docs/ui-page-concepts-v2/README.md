# Page concept notes

These three 1440 × 900 concepts translate the approved play and planning references into a calm, warm-ivory workspace with deep-blue actions, generous spacing, and the existing floating-island artwork. The home page gives the scenic journey art a full hero treatment and puts all five open worlds directly below it. Analytics keeps estimates task-specific and makes uncertainty, evidence links, saved history, and an unassessed state easy to scan. Quest presents the same five open branches with saved-activity milestones and participation XP visibly separated from task estimates. The tiny two-eye companion keeps its existing silhouette.

All visible profile values are synthetic design examples: the dimension statuses, 68% / 11 of 16 evidence-coverage example, saved-attempt counts and dates, and 240 XP. They do not describe a real learner, imply clinical meaning, or claim evidence from a live application. The footer identifies the images as design concepts with sample data.

Render locally from the workspace root with `powershell -ExecutionPolicy Bypass -File docs/ui-page-concepts-v2/render-concepts.ps1`. It uses Windows System.Drawing and reads only the existing local adventure artwork under `frontend/public/art/adventure/`.
